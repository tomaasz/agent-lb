# ADR: oddzielenie tożsamości proxy, księgowanie przed translacją i obraz runtime

2026-10-22, zaakceptowano w zakresie lokalnego audytu. BUG-001/002/003/010.

Relay usuwa wyłącznie własne cookie i rozpoznane poświadczenia proxy; zachowuje rzeczywistą tożsamość upstream. Księgowanie opiera się na surowym upstream SSE przed translacją, bo tłumaczenie może pomijać lub szacować usage. Końcowy scalony rekord powstaje raz także przy błędzie po częściowym usage. JSON normalizuje nazwy pól obu protokołów.

Obraz przechodzi na utrzymywany Node24 i aktualny Alpine; nie zawiera niewykorzystywanego przez runtime npm/yarn. Projekt dalej deklaruje Node>=20 dla użytkowników poza kontenerem; publiczne API bez zmian, poprawki zgodne z patch release. Nie zmieniono magazynu sekretów/CA. User osobno zatwierdził poprawki trzech instalatorów; alias Codex jest symlinkiem. Zastane zmiany użytkownika pozostają poza commitami audytu.
